# Badminton Tornooi

Installeerbare web-app voor badmintontornooien: teamtornooi en individueel tornooi met eerlijke planning en klassementsvoordeel.
Na de eerste keer openen werkt de app volledig offline.

**App:** https://carlvanoppens.github.io/badminton-tornooi/
Open de link op je telefoon en kies "Zet op beginscherm".

## Bestanden
- `src/badminton-tornooi.html`: de broncode van de app.
- `index.html`: wordt gemaakt met `python3 build.py`.
- `sw.js`: zorgt voor de offline werking. Verhoog `VERSION` bij elke nieuwe versie, dan krijgt de telefoon de update.
